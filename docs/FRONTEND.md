# 最小前端

React + TypeScript + Vite，源代码在 web/。已实现列表、发布、详情、筛选、登录、我的任务、申请至验收的协作面板，以及引航员聊天、个人待办和 AI 发布草稿。引航员说明见 [GUIDE.md](GUIDE.md)。暂未实现手机布局。

## 使用已构建页面

```powershell
Set-Location (git rev-parse --show-toplevel)
.\.venv\Scripts\python.exe -m uvicorn campus.app:app --host 127.0.0.1 --port 8000
```

任务大厅：http://127.0.0.1:8000/#/tasks

发布表单：http://127.0.0.1:8000/#/tasks/new

API 文档保留在 http://127.0.0.1:8000/docs。前端使用同源 /api 请求，无需单独启动前端开发服务。服务已经运行时不需要再次执行启动命令。

详情链接为 /#/tasks/任务ID，直接打开和刷新都能从 API 加载数据。搜索与分类保存在链接中，可用浏览器后退恢复。列表默认每页 20 条。

## 开发和重新构建

```powershell
Set-Location .\web
npm.cmd ci --ignore-scripts
npm.cmd run dev
```

开发地址为 http://127.0.0.1:5173，/api 代理到 8000，后端必须同时运行。

```powershell
npm.cmd run build
```

构建输出 web/dist。如果之前尚无构建目录，需要重启后端注册页面路由；已有目录时重新构建后刷新页面即可。不要提交 node_modules 或 dist；package-lock.json 保留以便复现依赖。

## 表单与状态

- 标题、分类、需求说明、完成标准、地点、截止时间必填，中文分类对应 API 英文枚举。
- 回报可以留空；截止时间按北京时间提交，明确带 +08:00。
- 发布者在未接取任务的详情页可点击“下架任务”。已下架任务退出大厅与待办，在“我的发布”和详情保留历史。
- 发布成功跳转新任务详情；失败显示提示并保留当前表单内容。
- 查询期间显示加载状态；无结果提示修改筛选；请求失败可重新加载。
- 全部任务内容按文本显示，保留段落换行，不当作 HTML 执行。

## 2026-10-14 验收

- TypeScript 检查与 Vite 生产构建通过，npm 安装审计报告 0 漏洞。
- 浏览器真实列表显示实际数据库中的两条摄影任务。
- 独立数据库验证搜索无结果、清除筛选、分类查询、发布跳转、详情刷新与直接打开。
- 独立测试服务停止后，查询显示连接失败；服务恢复后重新加载成功。
- 发布请求失败时，页面保留用户已填写的表单。
- 测试发布使用 .runtime/ui-verification.sqlite3，没有给实际任务库新增验收任务。

普通任务发布、详情及卡片现展示可选接取方式与填写要求，详见 [ACCEPTANCE.md](ACCEPTANCE.md)。
