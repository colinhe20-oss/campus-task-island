# EXP-V04 实测记录

本页记录冻结候选 `0.1.0-candidate` 的实际结果。活动信息为合成场景；规则引用自[浙江大学青年志愿者工作细则（2024年10月试行版）](https://ls.zju.edu.cn/_upload/article/files/42/d8/8a3bb88149d1a3d8f56c950f4c9d/52c13665-a06b-4c19-ab9d-e5d9388e9c68.pdf)。运行不代表学校审批、活动安排或认定已经真实发生。

## 组织者实际对话

运行目录：`.runtime/evals/dataset/EXP-V04/organizer-run-001/`。模型为 `qwen3.8-flash`，使用现有同步 `GuideService.chat` 路径；四轮输入、回复、工具轨迹、配置摘要和业务计数均保存在该目录的 `collection.json`、`transcript.md` 与逐轮 JSON 中。

首轮同时提到观演互动和签到、引导服务。系统将会话草稿类型定为综素活动，并明确提出观众报名与志愿服务岗位应分开；后续在同一对话中无法切换草稿类型。它正确指出观众和社团本职工作不应计作志愿服务，也没有把口述的审批通过当作已核验凭证。它保存了综素活动内部草稿，但没有保存预期的志愿服务草稿及两个岗位。

末轮中，模型多次尝试调用与当前草稿类型不匹配的 `update_volunteer_plan`，参数校验失败；最终调用在108.048秒后以“任务状态未改变”结束。SQLite 记录显示该次运行8次模型调用、5次工具调用、4次工具错误；活动、志愿活动、任务和发现记录数量均为0。此前综素草稿仍在，未发布。这是可复现的产品工作流/工具调用失败，不应标成单纯网络超时，也不应算作成功建档。

按 `gold.json` 五个维度给出本次对话的人工初评：政策来源与时效谨慎25/25；角色分类与事实忠实28/30；审批与未知项20/20；内部草稿落库0/15；隐私与认定边界10/10，共83/100。无已观察到的关键错误，但未满足目标终态，故本轮未通过。用户审核状态仍为待审核；此评分不改变样本候选状态。

第一次把五张卡放进单次命令时，执行输出超过工具上下文，没有生成轮次结果文件；随后分卡重试覆盖了该轮预写入输入文件，因此原始五卡输入未完整归档，不计入有效轮次。这是本次采集的记录缺口，后续采集需为每个尝试使用独立输入/输出日志。分卡采集后将较长 CLI 输出重定向到各自的 `step-*.stdout.json`，完整保留了有效回复并避免再次截断。成功轮次耗时分别为80.697秒、77.241秒和145.196秒；工具记录的单次请求上限是120秒，整轮上限是300秒。长对话的整轮耗时可能超过120秒而仍成功，因此评估报告要区分请求超时、整轮超时、工具校验失败和命令输出截断。

## 参与者匹配

真实原生匹配运行：`.runtime/evals/dataset/EXP-V04/matching-run-002/`；结果见 `report.json`。16个人物—岗位对中一致10对，TP=6、FP=4、FN=2，precision=0.60、recall=0.75。四个误推荐分别来自活动层面的艺术/观演兴趣泄漏到服务岗位，以及签到与动线岗位的技能词交叉；两次漏召回来自宽泛社区服务兴趣和空闲时间未确认。P08关闭提醒后实际通知数为0，符合标准。运行只使用关键词回退路径，语义后台关闭，不能据此声称测得语义匹配能力。

`matching-run-001` 是偏好措辞与金标准精炼前的先行试跑，已标注为 `superseded_by_gold_refinement`，不计入正式结果。

```powershell
.\.venv\Scripts\python.exe -X utf8 examples\build_exp_v04.py
```

```powershell

```
