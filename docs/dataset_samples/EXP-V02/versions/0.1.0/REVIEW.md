## 参与者矩阵

包含8组人物—机会条件，标签与理由见[participant_cases.json](participant_cases.json)。应分别记录推荐列表、限制说明和提醒触达；不能以自由到场推断完成全部认定，也不能以固定场次部分空闲推断可以参加。

## 复核重点

1. 保留活动时间、开放方式、容量、报名类型和参与要求。
2. 不捏造真实主办、场地授权、讲者、服务对象或认定结果。
3. 将候选展示、名额可报、完成条件和校方认定分开。
4. 固定班次完整出席与开放时段自由到场分别判断。
5. 关闭提醒、已报名、满额及未知时间等状态按矩阵评价。
