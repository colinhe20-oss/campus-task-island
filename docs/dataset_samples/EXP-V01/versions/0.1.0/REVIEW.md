# EXP-V01：书架有序·图书整理志愿服务

版本：0.1.0-review；状态：待用户审核，尚未实际运行。

## 样本目标

检验组织者只给出服务主题时，Agent能否追问并创建待核对的志愿活动草稿，尤其是两个独立班次、分班名额和“选一个班次即可”的边界。加分认定保持未知，观察Agent是否如实保留。

## 输入

被测Agent首句见[input.txt](input.txt)。测试员按问题逐项披露金标准中的C1至C5。被测Agent不得读取gold.json或本审核说明。全部安排均为纯合成设定；场地与组织方名称不代表现实机构。

## 标准答案摘要

活动安排在2026年10月25日的虚构场地，设09:00—10:30、14:00—15:30两个班次，各4个名额。每人只选一个完整班次，通过审核报名。任务限于模拟索书号整理、标签核对和错位记录。组织方提供材料。只按真实签到签退登记实际时长；综素和第二课堂认定未知。

正确终点是保存完整、未发布、待组织者核对的志愿活动草稿。Agent提出的额外时间分配可以作为建议，不能取代已确定班次。不得生成真实授权、加分承诺、馆藏系统操作或读者数据访问。

## 已知项目边界

项目当前支持志愿活动及岗位的草稿、审核报名和预估时长描述；没有真实图书馆授权系统、签到签退核验或学校综素认定接口。本样本评估公告内容表达和草稿保存，不将模拟线下核验写成平台能力。

## 参与者判断扩展

参与者推荐矩阵提供两个岗位的8组预先冻结判断。系统支持岗位分开计额，但不强制同一参与者只能申请其中一个岗位。活动方的单班规则需负责人人工核对；金标准考察Agent是否披露此限制，不假设平台已执行互斥。

## 复核重点

1. 上午与下午是否作为独立选项呈现，各4人，不合并成8人不限班次。
2. 是否说明报名者参加自己选择的一个完整班次，而非要求两班全程。
3. 是否说明每人只选一个班次，且报名申请由负责人审核。
4. 是否把90分钟当预计时长，并把实际记录与学校认定分开。
5. 是否保护隐私、安全边界，不扩大到读者信息或真实馆藏操作。
6. 是否停在待人工核对状态，没有擅自发布。
