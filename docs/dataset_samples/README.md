组织者样本包含首句、来源与模拟设定、固定底稿、披露卡和评分索引；参与者样本按独立人物和匹配判断规格记录。具体字段随任务类型变化，不强制所有样本套用同一事实数量。实际运行轨迹放在`.runtime/evals/dataset/<编号>/`，不覆盖冻结规格。

最初两条组织者样本采用20项事实与信息卡；PART-MATCH-001改用12个人物、24对推荐判断及分模块核对。PART-MATCH-001的运行世界使用2027年5月23日，书信内容仅在该运行副本中平移；其他扩增样本使用各自冻结规格中的业务时钟。

采集命令：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m examples.collect_letter_sample begin --sample ACT-XIAOMAN-001 --directory .runtime/evals/dataset/ACT-XIAOMAN-001/new-run
```

逐轮读取真实回复后，使用`step --cards C1 C2 ... --reason '选卡依据'`返回被问及的卡片；全部披露后加`--finish`。未知回复必须用`--unknown --unknown-topic '具体事项'`明确指代。必须使用新目录，不能覆盖或续写已结束的采集。

用户接受、静态结构就绪、实际采集完成和按评分规则通过分别记录。主动提供Agent未追问的卡片属于辅助补全，需要单独标记，不能据此声称自主澄清成功。基础设施失败保留为中断记录；内容错误保留为失败证据。

这些样本属于公开开发与演示集。同一原型的改写、对话和辅助变体按同一场景族管理；正式未见评测另行构造，不将同源变体拆到不同集合中。
