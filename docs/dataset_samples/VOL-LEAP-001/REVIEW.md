# VOL-LEAP-001：LEAP全球暑校志愿服务模拟招募

状态：0.1.0-review，待审核，尚未采集。来源是ZIBS 2025年6月24日官网历史通知；未来活动日期、组织者和报名窗口为模拟重设，不构成新一届官方通知。

## 首句

> 我们准备办一次面向国际学生的暑期学校，想招几位同学协助跨文化交流和活动协调。请帮我整理志愿者招募方案。

## 来源边界

官网历史通知明确了7月13—29日、海宁及沪杭多地点、全程参与、6名志愿者、身份/英语要求、职责，以及历史权益。模拟复办只复用这些历史结构作为实验依据；2027活动是否复办、是否提供历史权益、志愿小时数和每日岗位安排都未知。详情可查[官方原文](https://zibs.zju.edu.cn/2025/0624/c81949a3064400/page.htm)。

## 本样本要测的能力

Agent能否区分历史事实与模拟设定，准确传达全程参与和资格要求，且在排班、影像授权、时长未确定时追问并留空。不能通过编造服务小时数来满足系统岗位必填估时；此情形的正确结果是标记草稿未就绪。

完整底稿、5张信息卡、20条事实和8组参与者判断分别见gold.json与participant_cases.json。被测Agent不读取金标准。

## 首轮实测

3轮真实Guide对话已完成，结构化事实边界核对11/11。Agent保留岗位未定和累计时长未知，草稿因缺少必填岗位保持未就绪、未发布；它给出的岗位拆分仅留在待采纳建议中。操作者一轮披露全部信息卡，属于辅助完成。详见[实测报告](../../../.runtime/evals/dataset/VOL-LEAP-001/run-001/collection-report.md)和逐轮原始记录；样本仍待独立审核。
