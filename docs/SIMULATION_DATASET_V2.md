# 新版平台模拟业务数据方案（待审核）

> ✅ **已落地**：本方案已审核通过并落地为[第二版规格](SIMULATION_DATASET_V2_SPEC.md)及生成器实现，模拟库 v2run11 已生成并通过 216 项验收。本文保留作方案演进记录。

本文重新界定本轮交付：生成一个网页已持续使用一段时间的模拟业务数据库，沿用初版的账号、内容、关联记录与业务操作回放方式。交付中心是可浏览、可登录、可继续操作的业务环境。

本方案尚未生成数据库，也未改变当前模拟环境指针。此前的对话评测材料单独保留，不计作本方案的活动记录或业务数据完成量。

## 1. 依据与调整

初版依据为[模拟数据规格](SIMULATION_DATASET.md)与`examples/simulation_dataset.py`：50个模拟账号，120条主体内容；通过业务服务按时间回放产生关联记录，生成独立数据库与本机账号清单。

新版申报书`申报书 (1)(1).docx`的项目简介与主要内容将志愿服务、综素活动的组织、招募、参与作为核心；普通互助任务、校园发现作为后续拓展；同时强调技能、兴趣、空闲时间偏好、持续匹配、提醒和实际报名状态查询。

因此，新版调整业务构成与内容，保留初版已经建立的完整业务关系。以下数量为设计建议，申报书没有规定这些配额。

## 2. 建议规模与比例

先保持50个模拟账号、120条主体内容，便于与初版比较，优先改善内容与分布。

| 主体内容 | 初版 | 新版建议 | 新版占比 |
|---|---:|---:|---:|
| 志愿活动 | 20 | 48 | 40% |
| 综素活动 | 20 | 48 | 40% |
| 普通互助任务 | 50 | 12 | 10% |
| 校园发现 | 30 | 12 | 10% |
| 合计 | 120 | 120 | 100% |

活动占主体内容的比例由约33.3%提高至80%。岗位、报名、审核、参与记录、小时记录、评论、历史版本、偏好、推荐和消息属于关联记录，分别统计，不重复计作活动数。

## 3. 内容如何贴近校园

- 志愿活动覆盖书信公益、图书服务、环保、科普、赛事服务、展览协助与校园引导；岗位内容、资格、工作量、地点与班次应有区别。
- 综素活动覆盖画展参观、手作体验、美育讲座、文化游园、阅读分享、科创与体育文化活动；以参与方式和实际发布类型分类，不能因主题含公益就归入志愿服务。
- “夏日绘梦”类画展的观展记录归综素活动；若另有布展或现场服务招募，才建立关联的志愿活动。两者分别设置报名与资格，不混用名额。
- 已审核的书信活动、小满手作及偏好样例可提供内容原型；批量构造需要改变真实业务条件，不能只替换标题、日期或人名。
- 正文采用自然的活动通知表达，包含背景、安排、参与要求与联系渠道；结构字段与正文一致。来源、人物与活动均明确为模拟，不编造学校正式认定。

## 4. “已使用一段时间”的具体表现

先沿用初版过去28天、未来21天的时间窗口，生成时以观察时点整体平移。

| 维度 | 数据中应有的表现 |
|---|---|
| 用户 | 组织者、活跃参与者、普通参与者与低频用户；同一账号可组织也可参与 |
| 活动时间 | 尚未开放、正在招募、满额、截止未开始、进行中、已结束、已取消 |
| 报名与审核 | 申请待审核、通过、拒绝、候补、退出、递补以及活动取消后的关联状态 |
| 志愿参与 | 已参与、未到场、参与待登记、小时待确认与已确认；实际分钟数与岗位时间一致 |
| 热度 | 热门与冷门并存，有活动满额，也有活动报名较少；用户行为不能均匀复制 |
| 个人空间 | 不同账号可看到各自报名、负责人名单、待办、历史参与及站内消息 |
| 偏好与推荐 | 部分账号已授权偏好，部分未设置或关闭提醒；存在相关机会、时间冲突与无匹配机会 |

这些是业务表现与时间分组，实际存储和接口状态沿用现有服务规则。例如“已结束”不能擅自新增为活动存储状态，综素报名不能伪造当前产品尚不支持的签到或学校学分到账记录。

## 5. 生成与验收方式

1. 固定新版活动清单、人物画像、观察时点、时间与状态分布，再展开逐条内容。
2. 沿用并适配初版生成器，按历史时序调用现有业务服务创建活动、报名、审核、退出、递补和志愿记录；消息由对应业务操作触发。
3. 通过现有偏好保存及匹配服务生成推荐和提醒。模拟授权标注为生成器回放，不伪造真实用户或真实模型对话成果。
4. 验收主体数量、外键、状态、时间顺序、名额、报名权限、实际服务分钟、通知关系及不同账号的页面数据。
5. 交付独立SQLite数据库、可复现生成命令、设计键与业务ID映射、本机账号清单和统计报告；验收后再接入网页使用。

现有生成器对50任务、20综素、20志愿、30发现及特定编号流程有固定假设。新版需同步适配解析、回放与验收，不能只改文档中的数量。
