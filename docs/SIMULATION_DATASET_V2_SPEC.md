# 校园任务岛模拟数据集设计 v2

> 本文是第二版模拟业务数据库的**输入规格**，供生成器适配、回放与验收使用。它把[第二版方案](SIMULATION_DATASET_V2.md)（构成草案）落成可执行的完整清单。第一版规格见[模拟数据规格](SIMULATION_DATASET.md)，生成器 `examples/simulation_dataset.py` 与验收器 `examples/simulation_verify.py` 是本文的适配对象。

本规格当前修订为2.1，用于重新生成并验收日历与推荐故事修复版；实际发布目录与结果另见发布记录。此前“组织者对话、参与者对话、场景族”等评测材料单独保留，不计作本方案的活动记录或业务数据完成量。

## 1. 依据与调整

初版依据 50 账号 / 120 主体内容（普通任务50、综素20、志愿20、发现30），通过业务服务按时间回放产生关联记录。新版申报书把**志愿服务、综素活动的组织、招募、参与**作为核心，普通互助与校园发现作为后续拓展，同时强调技能、兴趣、空闲时间偏好、持续匹配、提醒与实际报名状态查询。

因此第二版做四件事：

1. **重配主体内容比例**：志愿 48 + 综素 48 + 任务 12 + 发现 12，活动占主体内容由约 33% 提高到 80%。
2. **内容贴近校园**：新增书信公益、展览协助、画展参观、手作体验、文化游园等主题；沿用并扩展岗位、班次、资格、地点、工作量的差异。
3. **补齐“已使用一段时间”的维度**：用户分层、活动时间分组、报名与审核全链路、志愿参与与小时核验、热度分布、个人空间、以及第一版没有的**偏好与推荐**。
4. **适配生成器**：现有生成器对“50任务/20综素/20志愿/30发现”有固定假设，本文同步给出解析、回放、验收的适配点，不只改文档数量。

以下数量均为设计建议，申报书未规定这些配额。

## 3. 基准、口径与业务边界

- **50 账号**：用户名 `sim_u001`—`sim_u050`，昵称统一加“模拟·”，发布标题统一加“【模拟】”；表格省略固定前缀。50 个账号不含系统内置 publisher/helper/observer。
- **E = 2026-10-19T18:00:00+08:00，种子 = 20261017**（固定基准，供发布到网页时复现业务 ID、关系与快照）。历史窗口从 `E-28d`（2026-09-21 18:00）开始，未来安排不晚于 `E+21d`（2026-11-09 18:00）。生成命令：`.\.venv\Scripts\python.exe -X utf8 -m examples.simulation_dataset generate --at 2026-10-19T18:00:00+08:00 --seed 20261017`。业务 ID、关系、操作次序与快照由 `seed+E` 唯一决定；密码及登录令牌每次随机。若要更换演示基准，可整体平移到其他整点（seed 不变），发布网页建议沿用本基准。文中 `E-2d`、`E+1d-9h` 等表达沿用初版语法，`C`=内容发布时间，`B`=首个报名时间。
- 校区、场所采用浙大校园背景；人物、社团、组织、来源公告均为虚构。不得据此宣称真实学校活动、学分认定或设施故障。
- 编号 U/T/V/A/D 是设计键，不作数据库主键；生成时保存设计键与真实 ID 映射。志愿岗位键为 `Vxxx-J1/J2/J3`。
- 50 个账号均 active；不新增专业、偏好、活跃度、权限角色字段到 users 表——**偏好单独存 `participation_preferences`**，与账号资料解耦。

### 3.1 状态与展示口径（沿用现有服务规则）

- 任务主状态 `published/in_progress/pending_review/completed/paused/cancelled`；待接取过期用 `is_expired`，进行中或待验收逾期用 `is_overdue`，暂停期间 `is_overdue=false`。下架为 `published + is_listed=0`，展示 `withdrawn`。
- 综素/志愿的 `status` 由服务端时间、取消标记、名额推导为 `not_open/open/full/closed/cancelled`。本文“进行中”“已结束”是时间分组，API 仍返回 `closed`。报名存储 `pending/registered/waitlisted/rejected/cancelled/activity_cancelled`；活动或岗位开始后未处理的 `pending/waitlisted` 对外显示 `not_selected`，不批量改写存储、不因此生成消息。
- 校园发现分类内选择状态：facility `unverified/verified/reported/in_progress/resolved`、safety `valid/invalid`、interesting/life `visible/expired`；来源始终 `author_report`，撤回写 `withdrawn_at` 不新增 withdrawn 状态。
- 志愿参与记录：`attendance ∈ {participated, absent}`、`actual_minutes`、`confirmed_minutes`、版本递增；`official_status=not_connected`、`official_minutes=null`，学校正式认定始终不生成。
